# ScopeAI

ScopeAI turns rough business ideas into structured project roadmaps for agencies, founders and product teams.

## Live site

https://scopeai-chgq.onrender.com

## Features

- Responsive landing page with light and dark modes.
- Interactive dashboard, settings, templates and help centre.
- Secure email/password sign-up and sign-in powered by Supabase.
- New Analysis submissions saved to Supabase project briefs.
- Responsive UI, motion preferences, password visibility control and logout confirmation.

## Tech

- Vanilla HTML, CSS and JavaScript
- Supabase Auth and Postgres
- Render Static Site hosting

## Run locally

Open `index.html` in a modern browser. For authenticated features, serve the folder with a local web server and configure the corresponding URL in Supabase Auth settings.

## Deployment

The `main` branch is connected to Render. Every new GitHub commit automatically triggers a fresh deployment.
